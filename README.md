# Efficient Quests

Efficient Quests is an experimental addon for World of Warcraft: Forever. An addon adds features to the game interface.

It shows practical quest and travel tips without choosing your next quest. The first version targets Forever 1.60.1 and TUG's Forever guide. It needs the separately installed QuestieDB addon. Guidelime, Questie, and FlareUI are optional.

The addon has offline tests, but its behavior and appearance have not been verified in the Forever client. It is not yet a validated release.

See the [installation guide](docs/installation.md) to install the addon and adapt a local guide. The [MVP specification](docs/specs/efficient-quests-mvp.md) describes the intended behavior. Two evidence notes record how the addon reasons and what remains unverified: the [local relevance notes](docs/local-relevance-evidence.md) cover how advice is tied to the player's location, and the [consumption notes](docs/consumption-evidence.md) cover supply requirements and flight-path observations. The [TUG extraction audit](docs/tug-extraction-audit.md) records the offline review of the supported guide. The [contribution guide](CONTRIBUTING.md) explains how to run the tests.

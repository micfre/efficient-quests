# Efficient Quests

Efficient Quests is a planned addon for World of Warcraft: Forever. An addon adds features to the game interface.

The addon will show tips for quests in your current zone. It will help you keep useful items, find flight paths, and avoid extra trips. You choose which quests to do.

The first version targets Forever 1.60.1 and TUG's guide. It will require QuestieDB, a separate addon that provides quest information. The tips window will work on its own or with the FlareUI quest tracker.

The project is in the planning stage. The addon and its installation tools are not ready yet.

The [MVP specification](docs/specs/efficient-quests-mvp.md) describes the planned features and checks. The [contribution guide](CONTRIBUTING.md) explains how to help with the project.

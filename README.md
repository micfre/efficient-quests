# Efficient Quests

Efficient Quests is an addon for World of Warcraft: Forever. The project is changing into one standalone addon with a built-in quest engine. The work is in progress.

This readme is a stub. A full rewrite comes with the standalone release. Until then, read the [standalone specification](docs/specs/efficient-quests-standalone.md) for the plan, and [CONTRIBUTING.md](CONTRIBUTING.md) for how to run the tests.

# Triage labels

Use these labels for the corresponding triage roles:

| Role | GitHub label | Meaning |
| --- | --- | --- |
| Needs triage | `needs-triage` | A maintainer must review the issue. |
| Needs information | `needs-info` | The issue needs more information. |
| Ready for agent | `ready-for-agent` | The issue is ready for an agent to implement. |
| Ready for human | `ready-for-human` | The issue needs a human to implement it. |
| Will not fix | `wontfix` | The project will not act on the issue. |

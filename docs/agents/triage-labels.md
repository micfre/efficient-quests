# Triage labels

Triage means to sort issues by what must happen next. Use these labels for the triage roles:

| Role | GitHub label | Meaning |
| --- | --- | --- |
| Needs triage | `needs-triage` | A maintainer must review the issue. |
| Needs information | `needs-info` | The issue needs more information. |
| Ready for agent | `ready-for-agent` | An agent can implement the issue. |
| Ready for human | `ready-for-human` | A human must implement the issue. |
| Will not fix | `wontfix` | The project will not act on the issue. |

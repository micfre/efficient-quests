# Agent instructions

## Documentation

For library, framework, SDK, API, CLI, or cloud service questions, use Context7. First resolve the library ID, then query the current documentation. Skip Context7 for general programming concepts, business logic debugging, code review, and refactoring.

## Agent skills

### Issue tracker

Track issues in GitHub Issues for `micfre/efficient-quests`. See `docs/agents/issue-tracker.md`.

### Triage labels

Use the default triage labels. See `docs/agents/triage-labels.md`.

### Domain docs

Use the single-context layout. See `docs/agents/domain.md`.
